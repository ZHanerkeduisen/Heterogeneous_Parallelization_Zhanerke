## Задание 4: Анализ производительности

Размер массива N = 1000000

CPU (OpenMP)        ---------------------------  0.00644 c (1×)

GPU (CUDA)          ---------------------------  0.000092 c (70×)

Гибрид CPU + GPU    ---------------------------  0.001437 c (4.48×)

GPU ускоряет вычисления значительно, а гибридный подход экономит время по сравнению с CPU, но чуть медленнее чистого GPU (так как половина массива всё ещё на CPU).

Факторы влияния на производительность: 
  
  1. Количество элементов массива (N)

     - При маленьких массивах GPU может работать медленнее CPU из-за накладных расходов на передачу данных.

  2. Передача данных CPU ↔ GPU

     - Каждое копирование через PCIe занимает время → чем меньше копирований, тем быстрее.

  3. Параллельная обработка

      - CPU использует ограниченное количество потоков (например, 4–8)

      - GPU использует тысячи потоков, поэтому при больших массивах выигрывает значительно.

## Выводы

1. Гибридный подход эффективен, когда:

   Массив большой

   CPU и GPU могут работать параллельно

   Есть ограничение на использование GPU только для части данных

2. Когда использовать CPU или GPU отдельно:

   Маленький массив → CPU быстрее (GPU накладные расходы)

   Большой массив → GPU быстрее

   Очень большой массив - гибридный режим помогает использовать все ресурсы

3. Как оптимизировать передачу данных:

   Минимизировать копирование между CPU и GPU

   Обрабатывать максимально большие блоки на GPU

   Использовать page-locked memory (CUDA pinned memory)
