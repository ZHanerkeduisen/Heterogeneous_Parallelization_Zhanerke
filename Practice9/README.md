## Задание 1: Распределённое вычисление среднего значения и стандартного отклонения (Practice9_Task1.ipynb)

Описание:
Программа вычисляет среднее значение и стандартное отклонение массива чисел в распределённой среде.

 - Процесс rank=0 генерирует массив данных.

 - Данные распределяются между процессами с помощью MPI_Scatter.

 - Каждый процесс вычисляет локальное среднее и стандартное отклонение.

 - Результаты собираются с помощью MPI_Reduce для вычисления глобального среднего и стандартного отклонения.

Особенности реализации:

 - Размер массива задаётся параметром программы.

 - Программа корректно работает при любом количестве процессов.

 - Используются функции MPI: MPI_Init, MPI_Comm_rank, MPI_Comm_size, MPI_Scatter, MPI_Reduce, MPI_Finalize.

## Задание 2: Распределённое решение системы линейных уравнений методом Гаусса (Practice9_Task2.ipynb)

Описание: Программа решает систему Ax = b методом Гаусса в распределённой среде.

 - Процесс rank=0 создаёт матрицу A и вектор b.

 - Строки матрицы распределяются между процессами с помощью MPI_Scatterv.

 - Прямой ход метода Гаусса выполняется параллельно.

 - Текущая ведущая строка рассылается с помощью MPI_Bcast.

 - После прямого хода локальные результаты собираются на rank=0, где выполняется обратный ход.

Особенности реализации:

 - Размер матрицы задаётся параметром программы.

 - Программа корректно работает при любом количестве процессов.

## Задание 3: Параллельный анализ графов (поиск кратчайших путей) (Practice9_Task3.ipynb)

Описание: Программа реализует алгоритм Флойда-Уоршелла для поиска кратчайших путей в графе.

 - Процесс rank=0 создаёт матрицу смежности графа.

 - Строки матрицы распределяются между процессами с помощью MPI_Scatterv.

 - Каждый процесс обновляет локальные строки для каждой итерации алгоритма.

 - k-я строка рассылается всем процессам с помощью MPI_Bcast.

 - После завершения всех итераций локальные блоки собираются на rank=0 с помощью MPI_Gatherv. - После прямого хода локальные результаты собираются на rank=0, где выполняется обратный ход.

Особенности реализации:

Размер графа задаётся параметром программы.

Программа корректно работает при любом количестве процессов.

Используется большое число INF для обозначения отсутствия пути.
